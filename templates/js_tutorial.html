Introduction to JavaScript

JavaScript (JS) is a high-level programming language that enables interactive web pages. It is used alongside HTML and CSS to create dynamic content, handle events, and manipulate the DOM.

JavaScript Examples

// 1. Display Alert
alert("Hello, World!");
Shows a pop-up message in the browser.
// 2. Console Log
console.log("This is a message in console");
Logs messages to the browser console, useful for debugging.
// 3. Variables
let x = 5;
const y = 10;
var z = x + y;
Declares variables using let, const, and var.
// 4. Data Types
let name = "Milan";
let age = 25;
let isStudent = true;
JavaScript has strings, numbers, booleans, arrays, objects, null, and undefined.
// 5. Functions
function greet() {
  alert("Hello!");
}
Defines reusable code blocks called functions.
// 6. Events
document.getElementById("btn").onclick = function() {
  alert("Button Clicked!");
};
Handles user events like clicks, hover, etc.
// 7. If-Else
let num = 10;
if(num > 5) {
  console.log("Greater than 5");
} else {
  console.log("Smaller or equal 5");
}
Executes code based on conditions.
// 8. For Loop
for(let i = 0; i < 5; i++) {
  console.log(i);
}
Repeats code multiple times using loops.
// 9. Arrays
let fruits = ["Apple", "Banana", "Mango"];
console.log(fruits[1]);
Arrays store multiple values in a single variable.
// 10. Objects
let person = {
  name: "Milan",
  age: 25
};
console.log(person.name);
Objects store key-value pairs for structured data.
// 11. String Methods
let str = "Hello World";
console.log(str.toUpperCase());
JavaScript provides methods to manipulate strings.
// 12. Math Operations
console.log(Math.sqrt(16));
console.log(Math.random());
Math object provides mathematical functions.
// 13. Date
let today = new Date();
console.log(today.getFullYear());
JavaScript Date object handles dates and times.
// 14. DOM Manipulation
document.getElementById("demo").innerHTML = "Hello JavaScript";
Change HTML content dynamically using JavaScript.
// 15. Template Literals
let name = "Milan";
console.log(`Hello, ${name}!`);
Template literals allow embedding variables inside strings.
// 16. Arrow Functions
const add = (a, b) => a + b;
console.log(add(5,3));
Shorter syntax for defining functions.
// 17. addEventListener
document.getElementById("btn").addEventListener("click", function() {
  alert("Clicked!");
});
Add multiple event listeners to elements.
// 18. JSON
let data = '{"name":"Milan","age":25}';
let obj = JSON.parse(data);
console.log(obj.name);
Parse JSON strings into JavaScript objects.
// 19. Local Storage
localStorage.setItem("name", "Milan");
console.log(localStorage.getItem("name"));
Store data in browser even after page reload.
// 20. setTimeout
setTimeout(() => {
  console.log("Hello after 2 seconds");
}, 2000);
Execute code after a delay using setTimeout.
