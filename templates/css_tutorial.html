Introduction to CSS

CSS (Cascading Style Sheets) is used to style HTML elements. It controls layout, colors, fonts, spacing, and responsiveness of webpages. CSS can be applied inline, internally in a <style> block, or externally via a separate stylesheet.

CSS Examples

/* 1. Text Color */
p {
  color: red;
}
Changes the text color to red.
/* 2. Background Color */
body {
  background-color: #333;
}
Sets the background color of the webpage.
/* 3. Font Size */
h1 {
  font-size: 36px;
}
Changes the size of the heading text.
/* 4. Font Family */
p {
  font-family: Arial, sans-serif;
}
Sets the font for paragraph text.
/* 5. Text Alignment */
h2 {
  text-align: center;
}
Centers the heading text horizontally.
/* 6. Margin */
div {
  margin: 20px;
}
Adds space outside the element.
/* 7. Padding */
div {
  padding: 15px;
}
Adds space inside the element.
/* 8. Border */
p {
  border: 2px solid #fff;
}
Adds a white border around the paragraph.
/* 9. Width */
div.container {
  width: 80%;
}
Sets the width of the container to 80% of parent.
/* 10. Height */
div.container {
  height: 200px;
}
Sets the height of the element.
/* 11. Display */
span {
  display: inline-block;
}
Changes how an element is displayed (block, inline, inline-block).
/* 12. Float */
img {
  float: left;
}
Floats image to the left of text.
/* 13. Text Decoration */
a {
  text-decoration: none;
}
Removes underline from links.
/* 14. Background Image */
body {
  background-image: url('bg.jpg');
  background-size: cover;
}
Adds a background image that covers the whole page.
/* 15. Opacity */
div {
  opacity: 0.8;
}
Makes the element semi-transparent.
/* 16. Box Shadow */
div {
  box-shadow: 0 4px 10px rgba(0,0,0,0.5);
}
Adds shadow around the box.
/* 17. Text Shadow */
h1 {
  text-shadow: 2px 2px #000;
}
Adds shadow to text.
/* 18. Border Radius */
div {
  border-radius: 10px;
}
Makes element corners rounded.
/* 19. Overflow */
div.box {
  overflow: auto;
}
Controls content overflow within a container.
/* 20. Transition */
div.button {
  transition: all 0.3s ease;
}
Animates changes to element properties smoothly.
