Introduction to Python

Python is a high-level, interpreted programming language known for its simplicity and readability. It was created by Guido van Rossum and first released in 1991. Python is widely used for web development, data analysis, artificial intelligence, scientific computing, automation, and more.

Python Examples

1. Hello World print"Hello, World!"

This program prints the text "Hello, World!" on the screen. It uses the print() function to display output.
2. Variable age = 20 name = "Alice" print("Name:", name) print("Age:", age)
This program demonstrates how to use variables in Python. It stores a name and age in variables and then prints them using the print() function.
3. Comments # Single-line comment print("Hello, CodeNest!") # Prints text """ Multi-line comment This is ignored by Python """
Shows single-line and multi-line comments. Python ignores text after # or inside """ """.
4. Data Types age = 25 price = 99.99 name = "CodeNest" is_active = True print("Age:", age) print("Price:", price) print("Name:", name) print("Active:", is_active)
Demonstrates Python data types: int, float, str, and bool.
5. Simple Operations a = 10 b = 5 # Addition sum = a + b # Subtraction diff = a - b # Multiplication prod = a * b # Division div = a / b print("Sum:", sum) print("Difference:", diff) print("Product:", prod) print("Division:", div)
Shows basic arithmetic operations using variables in Python: addition, subtraction, multiplication, and division.
6. Operators a = 10 b = 3 # Arithmetic Operators print("Addition:", a + b) print("Subtraction:", a - b) print("Multiplication:", a * b) print("Division:", a / b) print("Modulus:", a % b) print("Floor Division:", a // b) print("Exponent:", a ** b) # Comparison Operators print("Equal:", a == b) print("Not Equal:", a != b) print("Greater:", a > b) print("Less:", a < b) print("Greater or Equal:", a >= b) print("Less or Equal:", a <= b) # Logical Operators print("and:", a > 5 and b < 5) print("or:", a > 5 or b > 5) print("not:", not(a > b)) # Assignment Operators c = 5 c += 2 # c = c + 2 print("Assignment += :", c)
Demonstrates Python operators: arithmetic, comparison, logical, and assignment.

Conditional

7. If, Elif, Else x = 20 # Check if x is less than 10 if x < 10: print("x is less than 10") # Check if x is between 10 and 30 elif x <= 30: print("x is between 10 and 30") # If none of the above conditions are true else: print("x is greater than 30")
Demonstrates decision-making in Python using if, elif, and else.

loop's

8. For Loop - Simple Numbers for i in range(1, 6): print(i)
Prints numbers from 1 to 5 using a for loop and range().
9. While Loop - Simple Numbers i = 1 while i <= 5: print(i) i += 1
Prints numbers from 1 to 5 using a while loop.

String Function

10. Creating Strings str1 = "Hello" str2 = 'Python' print(str1) print(str2)
Shows how to create strings using double or single quotes.
11. String Indexing & Slicing text = "CodeNest" print(text[0]) # First character print(text[-1]) # Last character print(text[0:4]) # Characters from index 0 to 3 print(text[4:]) # Characters from index 4 to end
Access individual characters or parts of a string using indexing and slicing.
12. String Methods text = "CodeNest" print(text.upper()) # Convert to uppercase print(text.lower()) # Convert to lowercase print(len(text)) # Length of string print(text.replace("Nest", "World")) # Replace part of string
Demonstrates useful string methods: upper(), lower(), len(), replace().
13. String Concatenation & Repetition str1 = "Hello" str2 = "World" print(str1 + " " + str2) # Concatenation print(str1 * 3) # Repetition
Combine strings using + and repeat strings using *.
14. Lists fruits = ["Apple", "Banana", "Mango"] print(fruits)
Demonstrates a simple list in Python. Lists store multiple items in order.
15. Tuples colors = ("Red", "Green", "Blue") print(colors)
Demonstrates a tuple. Tuples are like lists but immutable (cannot be changed).
16. Sets nums = {1, 2, 3} print(nums)
Demonstrates a set. Sets store unique items and have no particular order.
17. Dictionaries student = {"name": "Alice", "age": 20} print(student)
Demonstrates a dictionary. Dictionaries store data in key-value pairs.
18. Defining Functions def greet(): print("Hello, CodeNest!") greet()
Defines a simple function using def and calls it.
19. Function Arguments & Return def add(a, b): return a + b result = add(5, 3) print(result)
Shows how to pass arguments to a function and return a value.
20. Lambda Function square = lambda x: x * x print(square(4))
Demonstrates a simple lambda function for small operations. lambda creates anonymous functions.
